# V4：字段依据与可核对的图表

2026-10-29。用户授权补充可信来源界面、逐字原文与原文链接，以及有实际用途的图表。延续冷白、炭黑与钴蓝；主页面只显示轻量依据入口，证据按需展开。本轮仅本地开发，不发布、不推送、不读取其他项目密钥。

## 来源与核验

1. 学费、学制、科目、招生人数、资格条件及历史成绩分别关联具体依据。每条依据包含官方发布单位、题名、年度、适用范围、原文摘录、精确页码或章节、发布日期、留档读取时间和官方链接。
2. 桌面右侧抽屉、手机全屏查看；支持关闭、Esc、焦点恢复和过时请求取消。从字段直接进入对应结论，避免让用户自行在整页链接中查找。
3. 全站来源页 `#/sources` 从次级入口打开，按单位、年度、资料类型与关键词筛选。它只说明当前已收录来源，不宣称全国专业资料完整。
4. 同内容的文件按摘要识别同源；支持同一结论、适用性引用链、背景材料和历史版本分别呈现。引用链和转载不能包装成多个独立印证。
5. 精确引文必须与保存原文字节及实际页码核对。保存快照核对成功不表示官网此刻可访问，也不代表所有资格条件完整。
6. 同年同范围、同收费口径的明确矛盾保留原值与各自依据，冲突字段停止以确定值参与排序。不按网页数量投票，不仅凭发布日期覆盖学院补充规定。

后端接口：

- `GET /api/evidence?program_id=`：项目身份、字段级claims、各自scope/status/evidence及summary。
- `GET /api/sources?unit_id=&year=&kind=&q=`：已收录来源、核对状态、同源标识及关联项目。

核心claim id为 `catalog`、`subjects`、`tuition`、`duration`、`enrollment`、`eligibility`；历史统计用 `history:<id>`，复试线用 `score:<id>`。状态区分 `verified`、`derived`、`needs_review`、`conflict`、`missing`。匿名统计属于程序计算，展示可重放的计算范围与真实表头原文，不能把程序生成的解释句伪装为官方逐字原文。

## 图表

| 图 | 用途 | 数据边界 |
| --- | --- | --- |
| 历年公示样本分数区间与中位数 | 比较对应专业的实际初试样本 | 固定最近三个已完成年度；缺年留空，不跨缺口连线；只有一年仍能查看真实区间 |
| 候选方案费用与学制比较 | 看清年费、全程费用和学习年限的取舍 | 年费与全程费用分别比较，未知不是0；按学习方式和统计口径解释，不制造录取概率 |
| 0/1/2科调整的路线覆盖 | 看清增加备考投入带来的候选增量 | 用同一范围的真实算法全量计数，方向/院系专业/学校分清，资格待核不显示成已可申请 |

历史图按学校、学院、专业、学习方式、计划、招生类别、样本范围和明确满分分组。初试、复试、最终成绩及复试线分别呈现。每个历史点可打开对应来源；每张图保留可阅读的数据和无障碍说明。没有逐人样本时不画分布密度，没有完整报名人数时不推算报录比。

可定向查找2025与2024官方公示；只有取得原文并核对口径后才增补。采集不到就保持缺失，不能为了图表连续补写数据。

## 分工与验证

- `evidence.py` 与service/server集成：精确原文、同源、作用域、冲突安全处理及HTTP边界。
- `static/evidence*.mjs/css`：统一证据抽屉与来源总览。
- `static/charts.mjs/css`：原生SVG/CSS图表，无新增运行时依赖。
- 既有前端入口与详情负责路由、字段入口、事件和可恢复交互；工作台接路线图。

先失败测试，再实现；回归包含伪造引文、相邻页、错误学校/年度/方向、同源重复、冲突值、空年份、单年图、未知费用、特殊计划分离、恶意URL/HTML、焦点恢复、切换请求及320px布局。最后统一运行Python、Node和真实Edge浏览器，并更新实际验收记录与截图。
