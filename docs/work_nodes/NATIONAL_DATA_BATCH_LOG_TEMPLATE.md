资格完整采用决定：真实适用条款是否齐全；所有引用是否当前有效；是否还有未解析、缺附件、例外或冲突；是否通过独立语义复核；采用文件及验证版本。任何一项不足，明确`eligibility_evidence_complete=false`及`requires_review=true`，同时保存已核部分。
