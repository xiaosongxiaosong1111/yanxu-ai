旧的同空间复建在取消或缓存失败后会丢失有效结果，虽然 active 指针仍相同。缓存写失败会丢失已知用量，查询超时、ANN 失败和取消时也缺少安全用量数据。普通知识写入会提前创建四张向量表，Milvus 释放失败没有可见信号。先修复这些问题，再推进 C1。

向量后台使用的真实模型与 SDK 验证均为本机离线小样本。34 道真实题目的配对评测属于 C2。远端厂商的测试使用模拟接口。复现脚本在 [独立探针目录](probes/independent-b/)。
