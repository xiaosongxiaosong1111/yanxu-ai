## 3. 修复的真实共性问题

1. **传输与文件类型。** TLS默认443的Host头、无扩展名CMS附件、HTML误标MIME的PDF/XLS、查询参数中的文件名。按容器签名识别，同时保留服务器原始响应头；未把类型识别当作目录结构通过。
2. **发布页到附件的完整链。** 识别VSB、SUDY、iframe/embed/object的受限静态引用，使用真实`base`解析。采集与`catalog_publication`消费同一关系证明，保留原HTML偏移；元数据标题不是伪造的可见正文引文。
3. **同校多个官方入口。** 有主域时仍重放原件中的额外入口；UCAS保留已核.ac.cn主入口，严格补证.edu.cn副入口。最近明确拥有者、跨句/跨段、外校、inert及平台推荐负例均拒绝，未依靠简称猜域名。
4. **静态学院索引漏采。** 只跟随已证明校年目录的静态groups与可见真实`a[href]`交集；BNU32个学院链接因此取得。普通章程、动态选择、隐藏或错校年不扩张。
5. **目录分类与范围。** 不把CHSI页面外导航、费用表当目录，不把零文字图片PDF判成无目录。PDF范围标题与紧邻独立副标题分别核对，不把正文“其中推免人数”当全篇仅推免。
6. **新增显式PDF v3。** 保留明确院系列与代码，核对完整学习方式格及严格续表网格；拒绝跨页未闭合初试、括号/缩略词误拆方向、方向全名并连及无凭据的空值填充。未按专业常识猜考试门数，真实MBA两单元与合法OR组合保留。
7. **重放和批准版本。** 解析缓存绑定依赖、完整单位上下文及选中入口证明。v3根审核绑定12份真实源码和完整记录集，9份非冻结依赖固定LF，五个冻结适配器原字节保持不变；Git提交字节逐项核对。

原先的284/295条中间集合未获批准，存在院系缺失、跨页初试不完整及方向误拆。最终固定代码与新274条集合重新审查，未沿用中间结果。
