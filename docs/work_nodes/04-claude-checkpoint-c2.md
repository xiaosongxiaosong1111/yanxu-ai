## 同输入的冻结真实评测

保持`tests/fixtures/knowledge_gold/**`全部字节、query和答案不变。原34题、29原件、17校、31适用题+3年份挑战、54适用引文/61总引文，两个旧split均已调试观察，不是盲测。

- 使用实际安全公开原件→N3提取/准入/分段→临时SQLite→真实固定本机Embedding→真实Milvus→C1混合检索→N3有限补读。不能拿固定向量或合成句子声称真实语义金标。
- 在同一原始自然语言question、相同scope、top_k和阅读预算下对比keyword与hybrid，另跑原冻结retrieval_query的N3基线以验兼容。严禁用自然语言hybrid对比手写keyword或调答案制造增益。
- 自然语言配对两路共享关键词预处理、规则重排和阅读预算，只切换语义召回；整句严格匹配是当前关键词实现的边界，不能据此宣传优于全部BM25或其他RAG。固定一次实际索引后顺序运行配对，记录同分稳定tie-break/ID机制、冷启动与热查询分开，防止临时UUID或首次加载差异冒充算法增益。
- 报每题来源Recall@k、引文提取/覆盖、学校年/状态和跨度/预算违规、延迟、Embedding输入/调用/缓存、已知和未知用量。没有价格不用编费用。改善和退步都列出；语义近似不代表资格/科目正确。
- 每题同时记录scope过滤后可用原件/片段数量：若范围内仅一份原件，source recall本身不足以证明排序优越，须结合必要引文覆盖与定位评估，不夸大该题难度；不为增加难度擅改冻结数据。
- 原N3两题远处限定语缺口和三题无年/发布链挑战要保留诚实结论；N4不靠放大无界阅读冒充解决N5规划。新增充分相关性上下文只能来自真实原文，合成嵌入上下文不能当连续引文。
- 三题挑战须实际验证eligible与keyword/hybrid返回来源中不包含未证实年度的条目，不只沿用旧评测的常量false。2024/2026/2027历史年不能改写成2028规则；年份未知始终未知，公示时间不能替代招生适用年。
- 权重已在工作区专属runtime可用。用临时DB，不访问实际用户库，不发送用户Key或收费调用。CPU threads2、小批次，报告模型revision/SHA和SDK锁定版本。实测未改善也必须如实报告。
