# 公共资料包与离线恢复

仓库中的 `bundles/` 保存可校验的公共资料分发包。Git 不直接跟踪本机的巨型 JSON、全部采集留档或运行数据库；首次克隆后，先恢复数据，再显式发布本机查询版本。

Windows 首次检出请选择有写权限的短目录，例如 `C:\src\yanxu-ai` 或 `D:\src\yanxu-ai`。旧原文引擎可能无法打开过长的完整 PDF 路径；不要在原项目的 `data/runtime/` 内再深层嵌套克隆。用于临时核验时，也应选择系统临时目录下较短的子目录。

```powershell
python tools/prepare_data.py
python -m pip install -r requirements.txt
# 按下文分别配置原文提取与坐标解析工具。
python -X utf8 -m collectors.publish_catalog --data-dir data
python -X utf8 server.py --port 4180
```

`prepare_data.py` 只用 Python 标准库，完全离线，不调用 AI、元宝或采集器，不读取凭据，也不创建已发布 SQLite。后续发布需安装项目依赖及原文解析工具，详见[运行说明](../docs/RUNNING.md)。`server.py` 不会静默发布 JSON；缺少已发布查询索引时，应先执行上面的发布命令。

### PDF 重放需要两个独立工具入口

本资料包的已有逐字引文使用 **Xpdf `pdftotext 4.00`** 的 `-raw -enc UTF-8` 输出；坐标表格使用 **Poppler 26.07.0** 的 `-bbox-layout` 及相邻 `pdftocairo`。两者不能互相替换：不同提取器可能改变空格与换行，既有引文或整表事实重放会拒绝发布。

Windows 本机已验收的原文工具来自 Git for Windows 的 `mingw64/bin`，坐标工具单独通过 `GRAD_PDFTOTEXT` 指定。请先确认两个可执行文件及相邻的 `pdftocairo.exe` 存在，下面只影响当前 PowerShell；安装位置不同时替换为实际路径：

```powershell
$rawPdfTool = 'C:\Program Files\Git\mingw64\bin\pdftotext.exe'
$bboxPdfTool = '<Poppler 26.07.0 所在目录>\pdftotext.exe'
$env:PATH = (Split-Path -Path $rawPdfTool -Parent) + ';' + $env:PATH
(Get-Command pdftotext).Source
pdftotext -v
# 上面应确认原文引擎为 4.00；坐标工具不加入 PATH。
$env:GRAD_PDFTOTEXT = $bboxPdfTool
& $env:GRAD_PDFTOTEXT -v
```

跨机器首次发布先核对两个入口、版本和项目完整路径。[运行说明](../docs/RUNNING.md)提供包内 PDF 的快速打开检查。如果出现文件存在但提取器仍返回非零退出码，应先排查长路径与工具配置，而不是断言数据包缺少原文。引文重放失败时保留原文和审校记录，不能改写 SHA 或降低审校标准使其通过。Linux/macOS 的工具配置和相同资料重放需要另行验证，不把安装任意版本 `poppler-utils` 等同于本次 Windows 验收环境。

## 此版本包含什么

资料用于 **2028 年入学规划，2027 年参考目录**；不把历史资料标作下一年度正式招生公告。

| 资料 | 公共包范围 |
| --- | --- |
| 招生单位身份 | 936 个通用索引，931 个年度独立招生单位及年度核对原文 |
| 专业与方向 | 135 个单位、22,356 条已采用目录记录，4,603 份目录文档上下文 |
| 费用与学制 | 7 条已有官方依据的补充规则；只用于其明确覆盖的专业和年份 |
| 学校参考线 | 6 条学校线，保留三年官方 PDF 与发布页；不当作专业线或录取分 |
| 历史调剂 | 1 条带历史范围的规则，不代表当前存在调剂缺额 |
| 待完善原表 | 389 行单独保存，缺关键字段的行不进入报考匹配 |
| 原文依赖 | 只分发上述采用资料及核验所需的原文闭包；不是全部历史爬取和发现档案 |

`bundles/manifest.json` 是精确清单：每个 ZIP、每个解压成员都记录字节数及 SHA-256。本版 9 个分片，压缩总量约 52 MiB，解压约 383 MiB；每个分片小于 50 MiB。原文保持其原始字节及摘要，目录中已有的未知项、条件备选和适用范围继续保留。

**全国专业与考试科目尚未全部收齐。** 院校索引、年度招生身份、实际采用的专业目录和字段核验分别计数；缺少资料不推断学校不招生。

## 公开分发时的排除规则

- 不分发 `data/runtime/`：API 凭据、研究任务、知识库、个人条件、雷达订阅与本机发布库均留在本机。
- 不分发全量发现库和未采用快照，避免把门禁页、历史垃圾材料或无关信息作为资料全集。
- 排除 3 份逐人录取结果原文及依赖它们的 6 条录取成绩统计。学校线仍保留；系统的匿名统计与历史图功能代码保留，但不能用这份公共包冒充已有可重放的逐人录取统计依据。
- 将单位登记中的本机绝对路径投影为仓库相对路径，保持原始材料 SHA 不变。不会修改构建者本机的原始 JSON 或原文。
- 不分发 Python 隔离依赖、Poppler 二进制、日志和测试缓存。使用项目依赖清单与运行说明安装。

只有在本机重新取得合法、可核验的历史来源并通过既有审校后，才能补充相应录取统计。复试线、学校线、录取初试统计和复试成绩是不同口径，不能相互代填。官网原文仍保留其发布者链接；使用材料时应分别遵守原发布页面的使用条件。

## 恢复过程的保护

恢复前会核对所有包和成员的 SHA、大小、数量及压缩包结构；检查全部通过后才添加文件。路径必须在目标项目的 `data/` 内，拒绝路径穿越、符号链接、Windows 路径别名、加密 ZIP 及写入运行库或分发包目录。

已存在且字节相同的文件直接跳过；已有不同内容时拒绝覆盖，保留你的资料。重复运行是幂等的。若已有本机完整采集资料，请保留原目录，使用新的克隆目录验证公共包，不要强行覆盖。

```powershell
# 可选：离线恢复到另一份已准备好的项目目录。
python tools/prepare_data.py --target-dir <新的项目目录>
```

## 维护者重建

`tools/build_public_bundle.py` 根据七份采用资料元数据计算文件依赖闭包，投影可移植路径、排除逐人历史材料后生成 ZIP 与 manifest。它不联网，不发布目录，也不修改原始输入。

```powershell
python -X utf8 -m unittest tests.test_data_bundle
python -X utf8 tools/build_public_bundle.py
```

新增或替换来源后，应重新审查精确成员清单、个人信息与密钥风险，并在全新的目录实际执行恢复、发布、HTTP 查询、算法和字段原文核验。压缩成功不代表数据正确，校验通过也不代表字段已经适用于当年报考。
